# Cargo Closed Launch — Phase 95

## 1. Цель закрытого запуска

Подготовить карго MVP к **первому закрытому запуску на 5–10 реальных пользователей**: понятный onboarding, короткие инструкции, сбор обратной связи, фиксация проблем, минимальные P0/P1 UX-правки.

Не цель фазы: чат, рейтинги, платежи, тарифы, CRM, сложная аналитика, Prisma refactor.

## 3. Что тестируем

- `/cargo` — hero, CTA, «Как это работает», feedback CTA
- Создание заявки (после входа) → success → `/cargo/requests/[id]`
- Отклики карго-компаний; владелец видит контакты отклика

## 5. Инструкция для клиента

### Как оставить заявку на перевозку

1. Откройте раздел **Карго**.
2. Нажмите **«Создать заявку»**.
3. Укажите откуда, куда и какой товар нужно перевезти.
4. Отправьте заявку.
5. Отклики карго-компаний появятся в личном кабинете в разделе **«Мои заявки»**.

### Короткий текст для WhatsApp / Telegram (клиенту)

```
Привет! Приглашаем в закрытый тест карго на TutOpt.

Как оставить заявку:
1) Откройте раздел Карго
2) «Создать заявку»
3) Откуда / куда / товар
4) Отправьте заявку
5) Отклики смотрите в «Мои заявки»

Если что-то непонятно или сломалось — нажмите «Сообщить о проблеме» на странице или напишите нам.
```

## 6. Инструкция для карго-компании

### Как получать карго-заявки

1. Создайте аккаунт.
2. Добавьте карточку карго-компании.
3. Откройте **«Карго-настройки»**.
4. Подключите Telegram.
5. Когда клиент оставит заявку, вы получите уведомление.
6. Откройте заявку и отправьте отклик с ценой, сроком и комментарием.

### Короткий текст для WhatsApp / Telegram (карго-компании)

```
Привет! Приглашаем карго-компанию в закрытый тест TutOpt.

Как получать заявки:
1) Аккаунт + карточка карго-компании
2) «Карго-настройки» → подключить Telegram
3) При новой заявке придёт уведомление
4) Откройте заявку → отклик (цена, срок, комментарий)

Проблемы: кнопка «Сообщить о проблеме» или напишите нам.
```

## 12. Решение: можно расширять / нельзя расширять

**Готово к закрытому запуску (5–10 человек)**, если:

1. Есть 3–5 клиентов + 2–5 карго + 1 оператор  
2. Telegram env проверен (или компании предупреждены, что notify опционален)  
3. Feedback mailto / URL работает  
4. Сценарии A–G пройдены оператором перед приглашением  

**Нельзя расширять** на открытый трафик, пока: есть открытые P0, или Telegram массово падает, или участники не понимают базовый loop заявка → отклик.
