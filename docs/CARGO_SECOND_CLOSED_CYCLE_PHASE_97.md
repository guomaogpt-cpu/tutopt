# Cargo Second Closed Cycle — Phase 97

## 1. Цель второго цикла

Провести **второй закрытый цикл** тестирования карго с реальными участниками: получить фактические заявки, отклики, Telegram-подключения и проблемы пользователей, чтобы команда вручную заполнила метрики и таблицу проблем.

Новые функции не добавляются. Чат, отзывы, рейтинги, платежи, тарифы, CRM — вне scope.

## 2. Почему нужен второй цикл

В Phase 96 пользовательская таблица проблем была пустая, поэтому невозможно принять решение о расширении запуска на основании фактических данных. Второй цикл нужен, чтобы получить реальные заявки, отклики, Telegram-подключения и проблемы пользователей.

См. также: `docs/CARGO_CLOSED_LAUNCH_RESULTS_PHASE_96.md`.

## 4. Что должны сделать клиенты

Готовый текст для отправки клиенту:

```
Здравствуйте. Мы тестируем новый раздел “Карго” на сайте ВсеТут.
Пожалуйста, откройте раздел Карго, создайте тестовую или реальную заявку на перевозку и проверьте, понятно ли вам:
1. где создать заявку;
2. какие данные нужно заполнить;
3. где потом найти свою заявку;
4. где смотреть отклики карго-компаний.

Если что-то непонятно или не работает — нажмите “Сообщить о проблеме” на сайте или напишите нам напрямую.
```

Краткий путь клиента:

1. `/cargo` → «Создать заявку» (нужен вход)
2. Заполнить маршрут и товар → отправить
3. Открыть `/cargo/requests/[id]` и `/account/requests`
4. Дождаться отклика и проверить контакты компании

## 5. Что должны сделать карго-компании

Готовый текст для отправки карго-компании:

```
Здравствуйте. Мы тестируем новый раздел “Карго” на сайте ВсеТут.
Пожалуйста, создайте аккаунт, добавьте карточку карго-компании, откройте “Карго-настройки”, подключите Telegram и попробуйте откликнуться на заявку.

Нужно проверить:
1. понятно ли, где добавить карго-компанию;
2. понятно ли, где подключить Telegram;
3. приходят ли уведомления;
4. удобно ли открыть заявку и отправить отклик;
5. понятно ли, что отклик отправлен.

Если что-то непонятно или не работает — нажмите “Сообщить о проблеме” на сайте или напишите нам напрямую.
```

Краткий путь карго-компании:

1. Аккаунт → карточка карго-компании
2. `/account/cargo-settings` → подключить Telegram → test
3. Открыть заявку → «Откликнуться» → confirmation
4. Сообщить оператору, пришло ли уведомление

## 6. Что должен делать оператор

### Ежедневный checklist

Каждый день теста:

- [ ] Проверить новые карго-заявки  
- [ ] Проверить, есть ли отклики  
- [ ] Проверить, кто подключил Telegram  
- [ ] Проверить, у кого Telegram не подключился  
- [ ] Проверить, есть ли заявки без откликов  
- [ ] Спросить клиента, понял ли он, где смотреть отклики  
- [ ] Спросить карго-компанию, пришло ли уведомление  
- [ ] Записать все проблемы в таблицу §8  

Admin (по необходимости): модерация карточек/объявлений, помощь с доступом.

### Feedback перед стартом

Желательно задать на production:

```
NEXT_PUBLIC_FEEDBACK_URL=https://wa.me/...   # или Telegram / форма
# NEXT_PUBLIC_SUPPORT_EMAIL=hello@tutopt.kg  # mailto fallback
```

Если `NEXT_PUBLIC_FEEDBACK_URL` не задан — UI использует mailto (`NEXT_PUBLIC_SUPPORT_EMAIL` или `hello@tutopt.kg`). Это **не P0**, но перед тестом лучше дать WhatsApp/Telegram ссылку.

## 9. Критерии успешности

### Можно расширять тест, если:

- P0 = 0  
- P1 не блокируют основной сценарий  
- минимум 3 заявки созданы  
- минимум 2 карго-компании смогли увидеть заявки  
- минимум 2 отклика отправлены  
- Telegram подключён хотя бы у 1–2 карго-компаний  
- owner видит отклики и контакты  

### Нужен ещё один закрытый цикл, если:

- P0 нет, но P1 много  
- пользователи часто не понимают, где создать заявку  
- карго-компании не понимают Telegram  
- заявки создаются, но откликов мало  

### Нельзя расширять, если:

- есть P0  
- есть privacy issue  
- заявки или отклики нестабильны  

## 10. Решение после цикла

После заполнения §7–§8 выбрать одно:

1. **Расширять тест** — критерии «можно расширять» выполнены  
2. **Повторить закрытый цикл** — P0 нет, но сценарий ещё путает  
3. **Остановиться и исправлять** — есть P0 / privacy / нестабильность  

_Решение заполнить после завершения второго цикла:_
