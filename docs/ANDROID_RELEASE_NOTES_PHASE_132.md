# Android Release Notes — Phase 132

**Версия:** 1.0.0 (`versionCode` 1)  
**Приложение:** ВсеТут  
**Package:** `kg.vsetut.app`

---

## Что доступно в 1.0.0

- **Объявления** — просмотр, поиск и фильтры
- **Разделы** — объявления, услуги, опт, карго
- **Подача объявления** — создание и отправка на модерацию
- **Заявки продавцам** — связь по объявлению
- **Личный кабинет** — объявления, заявки, избранное
- **Карго-заявки** — создание заявок на перевозку
- **Избранное** — сохранение объявлений
- **Жалобы** — сообщить о нарушении на странице объявления
- **Модерация** — проверка объявлений перед публикацией
- **Поддержка и правовые страницы** — privacy, terms, удаление аккаунта

---

## Ограничения текущей версии

- **Чат** — не доступен
- **Оплата внутри приложения** — не доступна; расчёты между пользователями вне приложения
- **Push-уведомления** — не включены в этой версии
- **iOS** — готовится отдельно
- **Доставка и гарантия сделки** — платформа не является стороной сделок
